# Postritme beheer

Leescontroles voor de publieke Postritme-website. Dit project bevat geen bankgegevens, betaalcodes of betaalde content.

De controle bekijkt bereikbaarheid en technische SEO van zes pagina’s. Zij koopt geen advertenties, publiceert geen berichten en verwerkt geen betalingen. Een geslaagde controle zegt niets over verkeer, ranking of omzet.

Gebruik: `python3 monitor.py`.

De geplande GitHub Actions-controle draait dagelijks. GitHub kan geplande uitvoeringen vertragen; openbare repositories kunnen na 60 dagen zonder activiteit hun planning verliezen. Controleer dan de Actions-pagina. Dit is technisch toezicht, geen autonome marketing- of omzetagent.
